# Design rationale

Packaging conversion has two separate failure modes: a natural-language statement can be interpreted in the wrong direction, and several individually clear statements can contradict one another. A single model answer cannot establish global consistency. A generic unit parser also cannot safely turn “up to six boxes” into a fixed factor.

RatioRail uses semantic consensus only to interpret one declared equality. Rational algebra handles composition and contradictions. Validators compare normalized mathematical meaning, allowing proportional count encodings while rejecting a wrong factor, direction or uncertainty status. They do not receive the leader's decision as a model input.

The graph's active subset is a forest built by component joins. A closing equality is either redundant or inconsistent with the unique existing path. This yields a compact, inspectable contradiction certificate rather than another AI opinion about which number should win. Models do not see previous ratios and cannot silently repair the statement to fit the graph.

The reusable output is a frozen complete rational table with immutable provenance and rejected-attempt history. Inventory adapters, catalogue tools and packing calculations can read exact conversions without trusting a private summarization server or running a fresh model call. The contract provides shared accepted computation, not independent certification of the declared facts.

The central invariant is multiplicative consistency of directed quantity equalities. An exact non-unit cycle product provides a checkable witness when declared equalities conflict.
